深度閱讀

1. When Does Latent Prediction Error Support Physical Surprise Claims in Video World Models?

arXiv:2611.01815｜cs.CV, cs.LG｜Technology School Electronic Systems (TUES)、Baba Tonka High School of Mathematics（保加利亞）

問題：V-JEPA 一類的 video world model 常被拿來做「intuitive physics」：看到不可能的事件時 latent prediction error 變大，就說模型「感到驚訝」。但 error 變大也可能只是畫面外觀改變、靜止畫面、運動量不同，或單純比較難預測。這篇問的是：這個推論什麼時候站得住？

方法：作者設計一套評估框架，分六項檢查：linear probe readout、latent geometry（各層 appearance shift 的大小、方向一致性、和物理變化的 subspace overlap）、action sensitivity、外觀與靜止畫面的對照、physical validity，以及固定 threshold 能不能遷移（calibration）。每個模型用自己的 encoder 和原生距離，所以只在同一模型內比大小。模型包括 V-JEPA2-G/L、VideoMAE2-G、低階像素統計 baseline，以及 action-conditioned 的 LeWorldModel、DINO-WM、JEPA-WM；資料集有 IntPhys2、Physion++ Mass、Kubric（自建的 256 組設定、3,072 段影片）、TwoRoom 和 PushT。統計上用 bootstrap 信賴區間加 Bonferroni 校正。

結果：在 IntPhys2 上，linear probe 判斷事件是否可能，V-JEPA2-G 只有 57.9%（VideoMAE2-G 49.2%、像素統計 50.0%），但判斷外觀高達 97.7%。也就是說物理資訊有，但很薄。最致命的是 Kubric 的交叉實驗：「停住」本身就比「掉落」error 高，所以在實心支撐上，不可能事件的 error 反而比可能事件低。用 calibration 場景擬合的單一 threshold，balanced accuracy 只有 53.9%，在實心支撐上只有 27.1%，約 69% 的合法影片被誤判成不可能。Physion++ 上，把單一 frame 重複（完全靜止）error 反而比原片高，整段改色調則讓 error 下降。Action-conditioned 模型對錯誤 action 確實會提高 error，但 DINO-WM 在 60° hue shift 下的 error 增量（0.0498）比錯誤 action 的增量（0.0031）大了一個數量級以上。

限制與疑問：Kubric 只有一個程序化場景家族，鏡頭、顏色、光線都受限，沒有測質量、摩擦等材質線索；幾個模型架構和預訓練都不同，所以無法單獨歸因到 JEPA objective。不過論文本來就是在說「這個推論不夠格」，而不是要提出更好的 surprise 指標。

為什麼值得看：如果你在做 world model 的 anomaly detection、或把 prediction error 當 planning cost，這篇等於一份檢查清單：至少要做靜止畫面、改色、跨場景 threshold 這三個對照。後續可以想的是：error 有沒有辦法在 appearance subspace 之外計算（論文顯示深層的 appearance shift 方向很一致，可以投影掉），以及用像 Kubric 這樣「可能/不可能」交叉配對的資料當作標準 sanity check。

2. Where Do Vision Language Models Fail at 3D Reasoning?（BedBench）

arXiv:2610.39639｜cs.CV, cs.AI｜作者含 Silvio Savarese、Ran Xu、Mona Diab 等（HF 頁標 Stanford）

問題：VLM 在單一 3D 問題上可能答對，但當答案需要「每個量都對、而且彼此對得上」時就崩了。作者區分三件事：individual judgment（例如有幾種顏色）、exact answer（每種顏色各幾塊都要對）、consistent use（相關問題的答案是否互相一致）。

方法：BedBench 有 13 個程序化生成的任務，大多是 10 到 15 個 unit cube 組成的 voxel 物體，從相反的兩個視角渲染，並過濾掉兩張 silhouette 會有歧義的物體，因此 ground truth 是精確的。有顏色/無顏色、有座標軸/無座標軸的對照版本。測了 12 個 open-weight（Qwen3.5、Gemma4、GLM-4.6V-Flash、Kimi-VL）和 4 個 frontier 模型（GPT-5、Grok-4.20、Gemini-3-Flash/3.1-Pro），另有 30 位人類受試者。

結果：per-color counting 是最大弱點：人類 93.3%，最好的模型 7.2%。平均下來人類 70.0%，最強的 Gemini-3-Flash 51.5%，永遠猜同一個答案的 baseline 是 36.7%。open-weight 模型的 per-color MAE 是 0.80 塊，比「每色都猜平均值」的 0.69 還差。同樣的方塊改用 2D tile 呈現，Qwen3.5-27B 的 exact match 從 3.0% 跳到 52.4%，問題確實在 3D。對 Qwen3.5-27B 做 LoRA（只訓 LLM、凍結 vision encoder），T5 從 3.0% 升到 68.6%，但問「哪個顏色最多」時，從圖片答只有 35.0%，把它自己數出來的 count 用文字餵回去就有 74.2%。Probing 更有意思：attention probe 從 connector 輸出能還原 65.0% 的精確 count，模型自己卻只答對 3.0%。資訊已經送進 LLM，是 LLM 沒用上。另外，拿掉圖片後有些分數還在，例如 Gemma4-31B 在 T1 靠永遠選第三個選項拿到 100%。

限制與疑問：場景全是合成 voxel，沒有真實材質、光線和雜亂；人類樣本只有 30 人；深入的 probing 和 fine-tuning 主要只做了 Qwen3.5-27B。

為什麼值得看：對做 spatial VLM 或拿 VLM 當機器人 planner 的人，「encoder 看得到，LLM 用不上」是很具體的診斷，也暗示改 connector 或加中間結構化輸出（先數再答）可能比加 3D 資料更有效。image-removal control 也該成為所有 3D VQA benchmark 的標配。

3. Does Validation Loss Predict Real-Robot Success?

arXiv:2611.00283｜cs.RO｜Simon Cowling，fysical.ai（丹麥）

問題：大家用 held-out validation loss 選 checkpoint、比較模型，但 imitation learning 有兩個問題：closed-loop 下小誤差會累積，而 demonstration 永遠是「任務已經開始」的樣子，有些失敗模式根本不會出現在 validation set 裡。

方法：一台低成本 SO-101 手臂，在兩顆紅球干擾下撿綠球丟進籃子。四種 policy：ACT、Diffusion Policy（未裁切與裁掉開頭靜止段的兩個版本）、SmolVLA、π0.5（只訓 action expert）。225 條示範中固定 25 條當 hold-out，訓練用 12/25/50/100/200 條的巢狀子集。共 82 個 checkpoint 對上 930 次真機 rollout，另外對 70 次訓練的 700 個中間 checkpoint 算 offline 指標。真機測試的光線比錄製時暗。指標包括各 policy 自己的 loss，以及統一的 action MAE，用 Spearman 相關加 permutation test。

結果：同一模型內，hold-out error 和成功率的相關從 −0.23 到 −0.88，但光用「示範數量」就能得到差不多的相關；固定資料量後相關接近零甚至為正（ACT +0.28）。跨模型更糟：200 條示範時 hold-out error 和成功率的相關是 +0.90，方向完全相反；未裁切的 DP 有全研究最低的 hold-out error，110 次只成功 3 次。最常見的失敗是手臂根本沒離開起始姿勢：未裁切 DP 96%、SmolVLA 47%，ACT 和 π0.5 都是 0。一旦手臂動起來，validation 就有用：SmolVLA 在「有啟動」的 rollout 中相關達 −0.81，SmolVLA 和 π0.5 的 hold-out error 幾乎一樣（4.98 vs 5.11），啟動後成功率也接近（71% vs 73%），整體差距（38% vs 73%）幾乎全來自啟動。EMA 讓 validation 變化不到 1.5%，卻讓 DP 啟動次數從 2/20 變 12/20；裁掉開頭靜止段讓成功從 2/40 變 34/70。另一個重點：DP 和 SmolVLA 的 hold-out denoising loss 在訓練中上升 2 到 5 倍，但 action error 反而下降最多 29%，用 loss 做 early stopping 會在約 10% 進度時就停掉。

限制與疑問：單一任務、單一手臂、單一實驗室；多數 checkpoint 只有 10 次 rollout（約 ±15 個百分點）；不同 policy 的 action horizon 不同（ACT 100、DP 24），跨模型 action error 不完全可比。

為什麼值得看：作者建議把「啟動失敗」獨立報告、改用 action error 而非 generative loss，並提出一個還沒實作的 offline initiation probe：把示範開頭幾幀丟進去，看預測動作會不會在一秒內讓手臂動。這是很容易做的 follow-up。對任何訓練 diffusion/flow-matching policy 的人，「loss 上升但 policy 變好」這點也值得記住。

快速瀏覽

  • Roz: A Taste Test for World Model Latents（2611.00612）：和第一篇互相呼應。作者發現熱門的 latent world model 在能化約成影像相似度的任務上表現好，但會丟掉質量、形變、摩擦、彈性等物理性質。Roz 有 10 個對比任務和 3 個連續任務，共 1,734 個場景，只需要能抽 latent 和一個距離函數，一次 forward 就能跑完。
  • Auriga：Task-Agnostic Agent Harness for Zero-Shot Manipulation（2611.01112）：在 RoboDojo 上，拿掉手臂執行後 GPT-6 Astra 的成功率從 22.5% 升到 76.2%，可見瓶頸在執行。Auriga 讓模型透過 tool call 或 Python 程式行動，提供校正過的 3D 量測、雙臂控制、執行前的軌跡預覽和執行中的偏離監控，拿下 RoboDojo 第一（57.7% 成功率），RoboCasa365 73.2%。
  • WorldSketch: Sketching World Models for Zero-Shot Mobile Manipulation（2611.00513）：不讓 VLM 直接出動作，而是讓它畫一個只含任務相關物體、接觸幾何和可能運動的極簡 kinematic world model，再交給 geometric planner 最佳化。Zero-shot 成功率 RoboCasa 91%、LIBERO-PRO 97%，在 RoboCasa 上比次佳 agent 高 58 個百分點，VLM input token 少 10 倍。
  • Gaussifier: Fast 2D Gaussian Decomposition（2611.00032）：feedforward 地把圖片分解成 2D Gaussian：先學 Gaussian 中心的 density map，用 equal-mass Voronoi cell 放置，再迭代 refine 幾輪。Kodak-24 上 40.73 dB、DIV2K 38.61 dB，超過 60 FPS，同 Gaussian 數下比 feedforward baseline 高 3.0 到 15.6 dB，有 WebGPU demo。
  • Advances in Agentic Computer Graphics（2611.01860）：Guibas、Jiajun Wu、Agrawala、Pavlakos、Shangzhe Wu 等人合寫的 survey（HF 89 upvotes）。提出跨圖學任務的 agentic system 統一分類，並附一個幫研究者大規模分析論文的 agentic 文獻系統，討論多 agent/工具協調、人機協作介面、長程規劃與互動系統的評估。
  • Lab2Sim（2611.02928）：把真實的科學實驗影片轉成可互動的虛擬實驗。Benchmark 有 218 部影片、11,881 個 rubric 項目；EduVideo2Code 先分層抽取流程、編成 state machine 引導程式生成，再用執行驗證修正，apparatus fidelity 提升 24.15 分。現有多模態模型能輕易生成可執行的網頁，但器材重建很差。
  • CUA-Master（2611.03126）：今天 HF 第二高（90）的 computer-use agent。雙層 flywheel：外層依模型弱點引入開放世界資料，內層從教學影片挖 workflow 當種子任務、合成可驗證任務，並用 snapshot-rollback 重試收集軌跡。27B 模型在 OSWorld Verified 拿到 80.2、OSWorld 2.0 36.9。

  • Astra「讀權重」爭議的兩個新角度：昨天的早報和晚報介紹過原文和第一篇反駁，之後又多了兩篇。Simon Willison 在筆電上用 Qwen 3.8 27B（Q4 量化、約 17GB）跑論文裡「不准用工具、只看原始權重猜是哪個遊戲」的實驗，Pong 和 Breakout 都猜對，Pac-Man 部分正確，Freeway 失敗，每題要 46 分鐘到一小時多（文章，HN 討論）。他認為這些網路只有幾萬個權重，一個有經驗的人拿紙筆也可能做到。spaCy 作者 Matthew Honnibal 則指出原文摘要誤導：真正「不用工具看權重」的只有實驗 1、2、4，而 Qwen 那個結果其實用了 Python 並實際跑模型；寫遊戲 policy 的實驗從零權重開始，也只在 Breakout 贏過 PPO（文章，HN 討論）。
