    介紹

    在上一篇文章中，我們知道Barnsley Fern與這次介紹的謝爾賓斯基三角形都是碎形。

    照慣例(XD)我們再次引用Wikipedia的內容

    謝爾賓斯基三角形（英語：Sierpinski triangle）是一種碎形，由波蘭數學家謝爾賓斯基在1915年提出。它是自相似集的例子。From Wikipedia

    我們這次所介紹的繪圖方法，維基百科把它稱作Chaos Game。也就是隨機的方法。

    主要的方法如下:

    1. 隨便畫個三角形(原始的謝爾賓斯基三角形為正三角形)
    2. 在三角形內部隨便找一個點P
    3. 從三角形三個頂點隨機找一個頂點
    4. 點出點P跟選定的頂點的中點
    5. 把那個中點當作新的點P
    6. 重複3.

    程式碼介紹

    這次的程式簡單到可以直接全部貼上來

     1# import package
 2import turtle
 3import random
 4import math
 5random.seed()
 6# 定義三角形三頂點
 7pointa = (0,400)
 8pointb = (-650,-300)
 9pointc = (650,-300)
10point = [pointa, pointb, pointc]
11# 定義第一個點(若這個點為隨機產出一樣對產出三角形完全沒有影響)
12firstpoint = (-200,250)
13
14# 定義繪點函數(傳入tuple)
15def drawdot(point, color='black'):
16	turtle.penup()
17	turtle.goto(point[0],point[1])
18	turtle.pendown()
19	turtle.dot(2, color)
20# 傳入兩個點(tuple)回傳兩點中點座標(tuple)
21def gohalf(point1,point2):
22	point = ((point1[0] + point2[0]) / 2, ((point1[1] + point2[1]) / 2))
23	return point
24# turtle package init
25turtle.speed(0)
26turtle.delay(0)
27turtle.hideturtle()
28# 開始繪圖
29drawdot(pointa)
30drawdot(pointb)
31drawdot(pointc)
32drawdot(firstpoint, 'green')
33# 將追蹤點定義為起始點
34tracepoint = firstpoint
35i = 1
36#進入無限迴圈
37while True:
38	print(i)
39	# 從point(list)隨機拿出任一個三角形頂點
40	random_point = random.choice(point)
41	# 產出中點座標
42	gopoint = gohalf(tracepoint, random_point)
43	# 描點
44	drawdot(gopoint)
45	# 將追蹤點定義為新產出的中點
46	tracepoint = gopoint
47	i += 1
48turtle.exitonclick()
